## 무엇인가

- 게임 손님 NPC용 테스트 캐릭터예요. 키는 약 1m이고, 머리가 몸의 절반쯤 되는 2등신이에요.
- "Mini Simple Characters" 스타일은 참고만 했어요. 그대로 따라 만들지 않았어요.
- Blender에서 손으로 만든 게 아니에요. `build_lowpoly_customer.py` 스크립트를 실행하면 모델 전체가 처음부터 다시 만들어져요.
- 고칠 때는 `.blend`를 직접 만지지 말고 **스크립트 숫자를 바꾼 뒤 다시 실행**하세요.
- 삼각형은 약 10,100개예요. 대부분 머리카락이에요.

## 실행 방법

```powershell
& "C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b -P build_lowpoly_customer.py
```

실행하면 다음 파일이 생겨요.

- `lowpoly_customer.blend`
- `fbx/lowpoly_customer.fbx` (Unity용, Y-up, -Z forward)
- `preview_front.png`, `preview_side.png`, `preview_back.png`

미리보기 세 장을 `preview.png` 한 장으로 붙이는 건 스크립트 밖에서 해요. 아래 PIL 코드를 쓰고, 다 붙인 뒤 `preview_*.png`와 `.blend1`은 지워요.

```python
from PIL import Image
ims = [Image.open('preview_%s.png' % n) for n in ('front', 'side', 'back')]
c = Image.new('RGB', (sum(i.width for i in ims), ims[0].height)); x = 0
for i in ims: c.paste(i, (x, 0)); x += i.width
c.save('preview.png')
```

## 스크립트 구조 (위에서부터 순서대로)

1. **재질**
   - Skin, Shirt, Pants, Shoes, Face(눈·눈썹), Hair, Mouth.
   - 단색이고 텍스처는 없어요.
2. **도우미 함수**
   - `sphere`, `cyl`, `box`: 기본 도형을 만들어요.
   - `shoe`: 앞코 윗부분만 둥근 신발을 만들어요.
   - `cut`: Boolean으로 잘라내요. 입을 반원으로 자를 때 써요.
3. **머리**
   - 머리통은 구 하나를 납작하게 늘린 거예요. 크기 (0.27, 0.25, 0.26).
   - 귀가 양쪽에 있어요.
4. **머리카락** (가장 손이 많이 간 부분, 아래에 따로 설명)
5. **얼굴**
   - 눈(세로 타원), 눈썹(얇은 상자), 입(원통을 반으로 잘라 만든 D자 웃는 입).
   - 코, 볼터치, 눈 하이라이트는 일부러 지웠어요.
6. **몸**
   - 목(짧은 원통), 한 덩어리 티셔츠, 반바지, 팔(A-포즈 20°), 손(구).
   - `LEG_EXTRA`(다리 연장)와 `NECK_GAP`(목 길이)만큼 윗부분 전체를 위로 올려요.
7. **다리·신발**
8. **마무리**
   - 전부 하나로 합쳐 `LowpolyCustomer` 오브젝트 하나로 만들어요.
   - 30°보다 꺾인 곳만 각지게 보이도록 음영을 처리해요(`shade_smooth_by_angle`).
   - FBX로 내보내고 Workbench로 미리보기를 렌더링해요.

## 머리카락 구성

모든 머리카락 위치는 "머리 둘레 각도(phi)"와 "높이 각도(elev)"로 정해요.

- phi: 0이 정면, ±π가 뒤예요.
- elev: 라디안이고, 위로 갈수록 커요.

- **두피 바탕** (`Hair`)
  - 구를 `hairline(phi)` 곡선 아래로 잘라낸 껍데기에 두께를 준 거예요.
  - 앞머리와 옆머리 밑을 머리카락 색으로 채우는 역할이에요.
  - **뒤쪽은 뚜껑 바로 밑까지만 남겨서 뒤통수에는 바탕이 없어요.**
- **뚜껑** (`HairLid`)
  - 정수리를 덮는 매끈한 덮개예요. 끝선은 `LID_KEYS`로 정해요.
  - 위쪽으로 갈수록 7% 부풀려서 볼륨을 줬어요.
  - 가닥들의 뿌리는 이 뚜껑 밑에 숨어 있어요.
- **가닥** (`strand()`)
  - 단면이 납작한 육각형이고, 끝으로 갈수록 가늘어지는 덩어리예요.
  - 머리 표면을 따라 내려오며 휘어요.
  - 주요 옵션:

    | 옵션 | 하는 일 |
    |---|---|
    | `drop` | 내려오는 길이 |
    | `curl` | 옆으로 쓸리는 정도 |
    | `width` | 반폭 |
    | `taper` | 클수록 끝이 뾰족해요 |
    | `lift` | 표면에서 띄우는 거리 |
    | `sink`, `sink_from` | 길이의 몇 % 지점부터 얼마나 머리 쪽으로 붙을지 |
    | `flat` | 끝으로 갈수록 얇아지는 정도 |
    | `frame` | 어느 표면을 기준으로 놓을지 |

  - 위치에 작은 무작위 차이를 줘요. 시드가 7로 고정이라 매번 같은 모양이 나와요.
- **앞머리**
  - 두 겹이고, 모두 화면 왼쪽으로 살짝 쓸려 있어요.
  - 아래층: 짧은 가닥 7개.
  - 위층: 긴 가닥 5개(`TOP_BANGS`).
  - 끝은 이마 쪽으로 붙게 했어요.
- **옆머리**
  - 양쪽에 3가닥씩 있어요. 볼을 따라 길게 2개, 귀 위에 1개.
  - 길이의 25% 지점부터 머리에 붙어서 떠 보이지 않아요.
- **뒷머리**
  - 넓은 덩어리 4개를 `HEAD_FRAME`(머리통 표면 자체)에 바로 붙였어요.
  - 아래로 갈수록 납작해지고, 목 위에서 뾰족하게 끝나요.

## 티셔츠 구성

몸통, 소매, 어깨를 따로 만들어 붙이면 이음새에 층이 생겨서, 아래처럼 한 덩어리로 만들었어요.

1. 정면에서 본 티셔츠 윤곽(`HALF` 좌표, 오른쪽 절반)을 그리고 좌우로 대칭시켜요. 윤곽은 목, 어깨선, 소매, 겨드랑이, 옆선, 밑단 순서예요.
2. 앞뒤로 `SHIRT_DEPTH`만큼 밀어내 두께를 줘요.
3. 복셀 리메시(0.012)로 면을 촘촘하게 만들어요.
4. 꼭짓점을 직접 옮겨 모양을 잡아요.
   - 옆으로 갈수록 얇게, 소매 쪽은 더 얇게 해요.
   - 앞뒤에서 옆선을 안쪽으로 당겨 단면을 타원으로 만들어요.
5. Smooth 모디파이어(14회)로 다듬고, Decimate(0.22)로 면 수를 줄여요.

어깨 기울기나 소매 길이는 `HALF` 좌표만 바꾸면 돼요.

## 사용자가 정한 방향 (다시 고칠 때 지킬 것)

- **모서리**: 너무 둥글지도, 너무 각지지도 않게.
- **넣지 않는 것**: 코, 볼터치, 눈 하이라이트, 엄지손가락, 티셔츠 주머니, 신발 밑창 색, 가방, 카라. 굳이 안 해도 되는 디테일은 넣지 않아요.
- **머리카락 전반**: 너무 자잘한 가닥은 싫어해요. 삐져나온 가닥도 넣지 않아요.
- **앞머리**: 참고 이미지(애니풍 소년 헤어)처럼 겹겹이, 한쪽으로 쓸리게.
- **옆머리**: 머리에 붙어 있어야 해요. 떠 보이거나 바깥으로 뻗치면 안 돼요.
- **뒷머리**: 3~4개의 큰 덩어리로, 뒤통수에 딱 붙게. 목덜미는 덮지 않아요.
- **티셔츠**: 일반 반팔 티(옷주름 없음). 어깨가 목에서 소매까지 층 없이 이어져야 해요.
- **비율**: 목은 짧게. 다리는 조금 길게 늘렸어요.
